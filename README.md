## 📁 Featured Projects

### 📊 [Statistical Analysis of Chemical Process Data](#)
> 3-month capstone project applying the full statistical toolkit to real process data.
- Descriptive statistics, normality testing, outlier detection
- Hypothesis testing (t-tests, ANOVA) on process variables
- Regression model with residual validation
- SPC control charts and process capability (Cp, Cpk)
- **Tools:** Python · Minitab · NumPy · SciPy · Matplotlib

---

### 📈 [Probability & Distributions — Python Toolkit](#)
> From-scratch Python implementations of all major distributions from Hines et al.
- Binomial, Poisson, Normal, Exponential, Weibull — PMF/PDF/CDF
- Z-score calculator, confidence interval tool, CLT simulator
- Interactive visualizations for all distributions
- **Tools:** Python · NumPy · SciPy · Matplotlib

---

### 🔬 [Hypothesis Testing for Engineers](#)
> Practical hypothesis testing toolkit with chemical engineering examples.
- One-sample & two-sample t-tests with real process data
- F-test for variance comparison
- ANOVA for multi-factor process comparisons
- p-value interpretation guide
- **Tools:** Python · SciPy · Pandas

---

### 🏭 [Statistical Process Control Dashboard](#)
> SPC control chart generator for monitoring process stability.
- X̄-R charts, I-MR charts, p-charts
- Automatic detection of out-of-control signals (8 Western Electric Rules)
- Process capability indices Cp and Cpk
- **Tools:** Python · Minitab · Matplotlib
